Nkɔsoɔ – Modular Crowdfunding Platform

BIT 268: Computational Systems and Problem Solving

Project Overview
Nkɔsoɔ is a modular crowdfunding platform designed to connect people who need financial support with individuals willing to contribute towards meaningful goals.

The platform allows users to:
- Create fundraising campaigns
- Browse active campaigns
- Make donations
- Track campaign progress
- View donation and campaign analytics

The project focuses on simplifying the crowdfunding process through computational thinking and system decomposition.

Problem Statement

Traditional crowdfunding platforms can become complex due to the number of processes involved, including campaign management, user interactions, payments, tracking donations, and analysing fundraising progress.

Nkɔsoɔ addresses this complexity by breaking the crowdfunding system into smaller, manageable modules that work together to create a simple and efficient user experience.


Computational Thinking Approach

This project applies *decomposition*, a computational thinking technique that involves breaking a complex system into smaller independent components before implementation.

The crowdfunding platform is divided into five major modules:
1. Frontend Development
Responsible for the user interface and user experience.

Technologies:
- React

2. Backend Development
Responsible for system logic, APIs, authentication, and communication between different components.

Technologies:
- Java Spring Boot

3. Database Management
Responsible for storing and organizing system information including users, campaigns, donations, and payouts.

Technologies:
- MySQL

4. Analytics and Reporting
Responsible for transforming stored data into meaningful insights through reports and visualizations.

Technologies:
- Chart.js
- SQL

5. Integration, Testing and Deployment
Responsible for connecting all modules, testing system functionality, managing collaboration, and deploying the final application.

Technologies:
- Git
- GitHub
- Postman
- Hosting Platforms

System Features

The platform includes:

- User registration 
- Campaign creation and management
- Campaign discovery
- Donation system
- Simulated MoMo and Visa payment process
- Donation history
- Campaign analytics dashboard
- Reporting features
